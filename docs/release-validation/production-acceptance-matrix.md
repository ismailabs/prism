## Executable final human acceptance

Use the exact accepted candidate/schema/worker revision, synthetic identities and no customer records. Record tester, date/MYT, actual device/OS/browser/assistive technology, language, expected/observed result, defects and retests. No result may be copied from a fixture test.

1. Open public/login pages; navigate entirely by keyboard; inspect actual browser 200%/400% zoom, text scaling, landmarks, focus, dialogs, labels/errors and intentional table scrolling. Listen with the actual screen reader in English and Bahasa Melayu.
2. On physical supported Android and iOS browsers, operate touch/virtual keyboard/rotation/safe areas and the same critical financial flows. Test supported PWA installation, standalone launch, restart, offline public fallback, reconnect without replay and explicit update.
3. With registration still restricted, complete bounded invited synthetic-account confirmation/recovery acceptance through a monitored test inbox; inspect delivery/authentication headers, fresh/expired/reused links and safe failure. The tester enters any new password privately. Public self-registration is tested during the approved cutover, then immediately checked for two-user isolation.
4. Create a native-currency account; reject MYR `1.234` with the associated precision message and zero writes; save valid `1.23`; edit/reload/logout/sign in and reconcile exact amounts. Repeat applicable zero/negative/currency-scale boundaries. Exercise budgets, debt repayment, goal contribution/idempotency, notes, reminders/calendar and forecasts without converting projections into records.
5. Record real privacy/legal/operations approval against the existing draft packet: controller and monitored contacts, purposes/processors/locations, retention/rights/backup re-erasure, intended users, incident roles and response, recovery objectives/custody and an RM0 quota/registration-pause envelope. Unresolved placeholders cannot be published.

Technical operator evidence and human acceptance remain separate. A failure is fixed and returned only for the affected retest. Unrestricted registration and the public-launch completion claim require all mandatory rows to pass.
